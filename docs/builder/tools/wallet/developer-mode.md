# Developer mode

Use developer mode to start a fresh Testnet wallet in Bread. Begin on the welcome screen, before setting up a wallet.

The Bread logo is above the welcome heading. The **Get started** and **Recover your account** actions appear below it.

1. Open Bread's welcome screen.
2. Tap the logo seven times to start Testnet wallet setup.
3. Continue through the Testnet wallet onboarding shown by Bread.

After the seventh tap, the wallet opens the Testnet onboarding flow. Complete that flow before using the wallet with a compatible Testnet application.

This entry starts a new Testnet wallet; it does not switch an existing wallet to another network or grant Mainnet access. For an existing account, follow [Bread recovery and backup](./recovery.md).
