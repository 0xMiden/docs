# Build with an agent

Use an agent to explain Miden source, plan an app, or implement a contract and frontend. Start with the release your project actually uses, then verify each result before moving to a network.

| Resource | What it provides |
| --- | --- |
| [Agentic tools](tools.md) | Rust, MASM and protocol knowledge skills plus Markdown command prompts |
| [Agentic templates](templates.md) | Existing repositories with contracts, tests, frontend code and project instructions |
| [Guided flow](first-app.md) | A sequence of source inspection, build, test and handoff steps you and your agent execute |

The tools bundle does not provide an MCP server, signer, node or transaction runtime. A guided flow does not grant execution permissions or prove a network transaction succeeded.

1. [Start here and set up matching context](setup.md).
2. [Choose a starter](templates.md).
3. [Build your first app](first-app.md).
4. [Verify the result](verify.md).
5. [Diagnose and recover](recover.md) when a stage fails.
6. [Prepare a network handoff](network-handoff.md).

These pages target v0.17. Select the documentation version matching your checkout. The current documentation channel can advance independently of a pinned project.
